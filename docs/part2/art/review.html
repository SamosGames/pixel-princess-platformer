5. Pipeline comparison

Recommendation: hybrid. Procedural sprites, tiles, UI, telegraphs and FX (proven, full animation volume, deterministic); ChatGPT for long parallax backgrounds and store key art. The ChatGPT Anna sheet becomes the design reference for the painter; switch characters to ChatGPT only if the Phase 0 side-by-side clearly wins.

Deterministic processing for ChatGPT sources

magenta key-out → crop → normalize (head height, feet baseline) → area-average downsample → OKLab quantize to the locked world palette (sprites: no dither; backgrounds: 2×2 Bayer) → outline / flash / aerial perspective → segment registration, horizon lock, min-error seam, loop → slice → assets/ + source hashes → validation and lane-contrast gate. npm run gen never calls ChatGPT; raw PNGs + prompts are committed source.
