# 👑 Принцесса: Путь к короне

Браузерный 2D-платформер от **SamosGames**: пройди шесть волшебных миров, собери сердца,
открой наряды принцессы и победи финального босса.

Игра рассчитана на короткие повторные забеги: время прохождения сохраняется, а лучший результат
можно отправить в таблицу лидеров Яндекс Игр.

## Возможности

- 6 уровней и финальная битва;
- контрольные точки, жизни и коллекционные сердца;
- постепенное открытие нарядов принцессы;
- отдельные механики и опасности в каждом мире;
- клавиатура на компьютере и сенсорное управление на телефоне;
- адаптивный ландшафтный режим и PWA для офлайн-запуска;
- сохранение прогресса и таблица лидеров через SDK Яндекс Игр;
- русский, английский и итальянский интерфейсы.

## Управление

- **Компьютер:** `←` `→` — движение, `Space` или `↑` — прыжок, `Esc` — пауза.
- **Телефон:** удерживай устройство горизонтально и используй экранные кнопки.

## Запуск локально

Проект — статический сайт без обязательной сборки. Для ES-модулей нужен HTTP-сервер:

```bash
python3 tools/serve.py 8137
```

Открой <http://localhost:8137>.

Проверки и упаковка:

```bash
npm install
npm test
npm run package:yandex
```

Готовый архив для консоли Яндекс Игр появится по адресу `dist/pixel-princess-yandex.zip`.
В архиве `index.html` находится в корне, серверная часть не требуется.

## Структура

- `src/` — сцены, уровни, управление, локализация и интеграция SDK;
- `assets/` — игровые изображения, музыка и звуки;
- `tools/gen/` — генераторы процедурных ассетов;
- `tools/test/` — браузерные и функциональные проверки;
- `promo/` — скриншоты, обложки и видеоматериалы для публикации;
- `privacy.html` — политика конфиденциальности;
- `LEGAL.md` — сведения о лицензиях и публикации.

## Технологии

Vanilla JavaScript ES modules, [Kaplay](https://kaplayjs.com/) `3001.0.19`, HTML/CSS и
процедурные игровые ассеты. Сборка не нужна: браузер запускает статические файлы напрямую через
локальный сервер или хостинг.

## Публикация

Проект подготовлен для размещения в Яндекс Играх. Рекламные форматы, облачные сохранения и
таблица лидеров подключаются только при наличии SDK; локальный запуск продолжает работать без
него.

Промо-материалы находятся в `promo/`. Для публикации используйте русские скриншоты, горизонтальную
обложку и вертикальный ролик из этой папки.
